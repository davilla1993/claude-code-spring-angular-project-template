Exécute le bootstrap décrit dans `docs/DEVELOPMENT_WORKFLOW.md` : lis ce fichier maintenant et suis ses phases dans l'ordre.

Rappels :
- Aucun code de fonctionnalité, aucun test lancé : seuls des fichiers de `docs/` sont écrits.
- Si `docs/cahier-des-charges.md` est absent ou vide, arrête-toi et demande-le.
- Un seul lancement de l'agent `architecte`. C'est toi qui écris les documents à partir de son rapport.
- Termine par la revue de la dernière phase, puis arrête-toi et attends la validation de l'utilisateur.
